<summary><b>&nbsp;What each one actually proves</b></summary>

<br>

| Project | What it shows |
| --- | --- |
| 🛡️ **TrustMesh** | On a time split, XGBoost with four graph statistics beat every graph neural network tried (0.7482 vs 0.5913 PR-AUC). A voice model that looked too good (EER 0.0097) was reading leading silence; after trimming it scored 0.2380. Limits are listed first. 195 Python and 97 frontend tests. |
| 🌍 **Climate-Domain SLM** | Qwen2.5 tuned to answer from a passage or refuse. 1.5B SFT: F1 0.791, 0/32 false refusals, 11/11 correct refusals. DPO v1 failed and is reported as failed. DPO v2's gain sits inside overlapping intervals, so no claim is made. vLLM was about 3 to 4 times faster than plain transformers on a T4. 405 tests. |
| 🌾 **Grounded Climate Analyst** | A LangGraph pipeline with per-horizon forecast labels (t+1 validated, t+2 weak, t+3 no skill) and a non-LLM checker that verifies every number in a report (precision 1.0, recall 0.9286). Heat forecasting had no skill and is reported as a null result. 556 backend tests. |
| 🛒 **Grow Vyaapar** | One codebase for eight kinds of shop. Seven agents that never send anything by themselves. The churn model's ROC-AUC is below the project's own target, and that is reported, not tuned away. 406 tests. |
